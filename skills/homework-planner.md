---
name: homework-planner
description: Turn the current homework list into a prioritized day-by-day study plan.
---
1. List every unfinished assignment ordered by due date.
2. Estimate effort (short / medium / long) from the title and description; ask if unclear.
3. Work backwards from each deadline and assign work blocks of 25-50 minutes.
4. Put the hardest or longest tasks earliest; leave one buffer block before each deadline.
5. Output a table: Day | Block | Course | Task | Est. time.
